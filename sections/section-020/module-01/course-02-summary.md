# Summary

DORA metrics describe software delivery performance through defined throughput and instability evidence. Traditional teaching commonly names four keys; the current model also distinguishes deployment rework rate and uses failed deployment recovery terminology. Definitions and populations should be version-aware. Platforms can improve delivery conditions, but aggregate counts do not prove causation or individual productivity. Use service-level context and complementary user evidence to understand what a change actually improves.
