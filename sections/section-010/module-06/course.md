# Cost And Resource Efficiency Of The Platform

A platform spends money: compute for the environments it creates and people to run it. A platform team must show that the money buys value, and it must find waste without blaming the teams that use the platform. This module teaches how to measure resource use, allocate cost, find waste and report the value of the platform. The hands-on work uses team resource data stored in ConfigMaps and read with `kubectl` and `jq`.

## Learning Goals

- Explain resource requests, limits and usage in Kubernetes, and compute utilization.
- Allocate cost to teams (showback and chargeback) and compute unit costs such as cost per environment.
- Find waste in cores and in money, name idle environments and explain rightsizing.
- Report the value of the platform to different audiences without vanity numbers.

## Before You Start

You should know what a ConfigMap, a namespace and a Kubernetes pod are. Terms are defined where they first appear.

## Reading Order

1. Resource Requests, Usage And Utilization
2. Cost Allocation And Unit Costs
3. Waste, Idle Environments And Rightsizing
4. Reporting Platform Value To Stakeholders
5. Summary
