# Developer Productivity Frameworks: SPACE, DevEx And Cognitive Load

Developer productivity cannot be described with one number. This module teaches two frameworks that platform teams use to choose a balanced set of measures: SPACE and the Developer Experience (DevEx) framework. It then shows how to measure cognitive load and how to build a metric set that does not harm the people it measures. The hands-on work uses a catalogue of metrics stored in a ConfigMap and read with `kubectl` and `jq`.

## Learning Goals

- Explain why a single metric fails to describe developer productivity.
- Name the five SPACE dimensions and give one workflow measure and one perceptual measure for each.
- Name the three DevEx areas: feedback loops, cognitive load and flow state.
- Name ways to measure cognitive load and friction in a platform.
- Build a balanced metric set of team-level measures and explain why individual-level activity metrics are avoided.

## Before You Start

You should know what a ConfigMap and a namespace are in Kubernetes. Terms are defined where they first appear.
